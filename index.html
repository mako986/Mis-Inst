mis-inst v3.3.2

mis-inst (mis Installer) — консольная утилита на Rust для автоматической генерации нативных .msi инсталляторов Windows с использованием WiX Toolset v4/v7.

⚡ Особенности

  • Embedded CAB: Архив с файлами дистрибутива вшивается прямо внутрь .msi пакета.
  • UI Wizard: Полноценный мастер установки на базе WixToolset.UI.wixext.
  • Поддержка кириллицы: Корректная обработка русских путей и имён (Language="1049", Codepage="1251").
  • Автогенерация GUID: Динамическое формирование уникальных UpgradeCode и Component GUID через uuid.

🛠 Системные требования

  • ОС Windows 10 / 11 (x64)
  • .NET SDK (для работы WiX)
  • WiX Toolset v4+: dotnet tool install --global wix

📋 Синтаксис CLI

mis-inst.exe <INPUT> <OUTPUT> <NAME> [-t <THEME>]
Параметр Тип Описание
<INPUT> Позиционный (1) Путь к исходному файлу (.exe, .apk и др.).
<OUTPUT> Позиционный (2) Имя создаваемого .msi пакета.
<NAME> Позиционный (3) Название программы в мастере установки.
-t, --theme Опциональный Тема оформления: classic, red, или photo <path>.

💡 Примеры использования

# Базовая сборка
mis-inst.exe my_app.exe Setup.msi "My Super App"

# Красная тема оформления
mis-inst.exe app-release.apk DRON.msi "DRON Simulator" -t red

❓ Решение проблем

Файл весит 0 КБ: Завершите зависший процесс установки через taskkill /F /IM msiexec.exe.

Бинарник 0 КБ при сборке Cargo: Выполните cargo clean, затем cargo build --release.
