# mis-inst (mis Installer)

**mis-inst** — это консольная утилита на Rust для автоматической генерации нативных .msi инсталляторов Windows с использованием WiX Toolset v4/v7.

Утилита принимает на вход дистрибутив программы, настраивает параметры установки, генерирует валидный XML-манифест .wxs и собирает готовый однофайловый пакет установки с графическим интерфейсом (UI Wizard).

---

## ⚡ Особенности

* **Однофайловая сборка (Embedded CAB):** Архив с файлами приложения вшивается прямо внутрь .msi пакета без создания внешних .cab архивов.
* **Графический интерфейс (UI Wizard):** Полный мастер установки с выбором директории, кнопками «Далее», «Установить» и отменяющим диалогом на базе WixToolset.UI.wixext.
* **Поддержка кириллицы:** Полная совместимость с русскоязычными именами, путями и описаниями (Language="1049", Codepage="1251").
* **Динамическая генерация GUID:** Каждая сборка автоматически получает уникальные идентификаторы UpgradeCode и Component GUID через библиотеку uuid.

---

## 🛠 Системные требования

1. **Windows 10 / 11**
2. **.NET SDK** (для работы WiX v4/v7)
3. **WiX Toolset v4+**
   Установка WiX выполняется одной командой:
   dotnet tool install --global wix

---

## 🚀 Сборка из исходников

Для сборки исполняемого файла mis-inst.exe:

cargo build --release

Готовый бинарник будет находиться по пути:
	arget/release/mis-inst.exe

## 📋 Синтаксис и параметры CLI

mis-inst.exe <INPUT> <OUTPUT> <NAME> [-t <THEME>]

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| <INPUT> | Позиционный (1) | Путь к исходному файлу дистрибутива (например, pp-release.exe или pp-release.apk). |
| <OUTPUT> | Позиционный (2) | Имя или путь для создаваемого установочного .msi пакета. |
| <NAME> | Позиционный (3) | Название приложения (отображается в мастере установки и в Program Files). |
| -t, --theme | Опциональный | Тема оформления мастера установки: classic, ed, или photo <path>. |

## 💡 Примеры использования

### Базовая сборка с классической темой
mis-inst.exe C:\builds\my_app.exe Setup.msi "My Super App"

### Сборка с красной темой оформления
mis-inst.exe C:\Users\user\AndroidStudioProjects\DRON\app\build\outputs\apk\release\app-release.apk DRON.msi DRON_SIMULATOR -t red

### Сборка с кастомным изображением темы
mis-inst.exe C:\builds\game.exe GameSetup.msi "Awesome Game" -t photo C:\assets\banner.png

## ⚙️ Как это работает внутри

1. **Парсинг CLI:** mis-inst считывает позиционные аргументы и флаги с помощью библиотеки clap.
2. **Генерация манифеста:** Формируется файл DRON.wxs на языке WiX v4 (xmlns="http://wixtoolset.org/schemas/v4/wxs").
3. **Настройка параметров пакета:**
   * <MediaTemplate EmbedCab="yes"/> указывает компилятору упаковать все файлы внутрь .msi.
   * <ui:WixUI Id="WixUI_InstallDir" .../> подключает графический интерфейс.
   * Language="1049" и Codepage="1251" исключают ошибки кодировки кириллицы (WIX0311).
4. **Компиляция:** Вызывается команда wix build DRON.wxs -ext WixToolset.UI.wixext -o <OUTPUT>.
5. **Очистка:** Удаляются временные файлы отладки .wixpdb, оставляя только готовый рабочий .msi."# Mis-Inst"
