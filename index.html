mis-inst v3.5.2

mis-inst (mis Installer) — консольная утилита на Rust для автоматической генерации и нативной сборки .msi инсталляторов Windows через WiX Toolset v4.

⚡ Особенности

  • Embedded CAB: Архив с файлами дистрибутива вшивается прямо внутрь .msi пакета.
  • Темы оформления: classic (классический синий стиль WiX v3 / Advanced Installer с боковой панелью), red (красный стиль) или photo (собственное изображение).
  • Упаковка доп. файлов: Включение любых сопутствующих файлов (.dll, .json, .db) через флаг -e / --extra.
  • Поддержка кириллицы: Корректная обработка русских путей и имён (Language="1049", Codepage="1251").
  • Автогенерация GUID: Динамическое формирование уникальных UpgradeCode и Component GUID через uuid.
  • Автоочистка: Удаление всех временных .wxs, .wixpdb и автосгенерированных .bmp файлов сразу после сборки.

🛠 Системные требования

  • ОС Windows 10 / 11 (x64)
  • WiX Toolset v4+ (с установленным расширением UI): wix extension add WixToolset.UI.wixext

📋 Синтаксис CLI

mis-inst.exe <INPUT> <OUTPUT> <NAME> [-d <DEVELOPER>] [-t <THEME...>] [-e <FILES...>]
Параметр Тип Описание
<INPUT> Позиционный (1) Путь к основному исполняемому файлу (.exe).
<OUTPUT> Позиционный (2) Имя или путь создаваемого .msi пакета.
<NAME> Позиционный (3) Название программы в мастере установки.
-d, --developer Опциональный Имя издателя / разработчика (по умолчанию: "Developer Studio").
-t, --theme Опциональный Тема оформления: classic, red, или photo <path> (по умолчанию: classic).
-e, --extra Опциональный Список дополнительных файлов для включения в установщик.

💡 Примеры использования

# Базовая сборка (синяя классическая тема)
mis-inst.exe JokerUnlocker.exe Setup.msi "Joker Unlocker"

# Указание разработчика и дополнительных файлов
mis-inst.exe SilenceRemover.exe SilenceRemoverSetup.msi "Silence Remover" -d "Mako Dev" -e ffmpeg.exe config.json

# Красная тема оформления
mis-inst.exe app.exe setup.msi "My Application" -t red

# Кастомная фоновая картинка
mis-inst.exe app.exe setup.msi "My Application" -t photo "C:\Images\banner.bmp"

❓ Решение проблем

Файл весит 0 КБ: Завершите зависший процесс установки через taskkill /F /IM msiexec.exe.

Ошибка сборки WiX UI: Убедитесь, что установлено расширение UI: wix extension add WixToolset.UI.wixext.

Бинарник 0 КБ при сборке Cargo: Выполните cargo clean, затем cargo build --release.
